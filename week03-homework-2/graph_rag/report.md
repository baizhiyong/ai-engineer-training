# GraphRAG 多跳问答系统 - 实验结果分析报告

## 1. 项目概述

本项目旨在构建一个基于知识图谱 (KG) 和文档检索 (RAG) 的多跳问答系统。系统的目标是回答需要结合结构化数据和非结构化文本的复杂问题，特别是学科知识点的应用场景。核心技术栈包括：

- **API 框架**: FastAPI
- **知识图谱**: Neo4j
- **检索与编排**: LlamaIndex
- **向量存储**: 本地 CSV 数据
- **LLM 与嵌入模型**: DashScope 提供的 `qwen-plus` 和 `text-embedding-v3`

系统通过一个 API 接口接收自然语言问题，执行“文档检索 -> 图谱查询 -> 综合生成”的多跳推理流程，并返回答案及推理路径。

## 2. 核心功能测试与分析

我们围绕“查询学科知识点的跨领域应用”这一场景进行了测试。

### 2.1. 测试场景

- **用户问题**: "指数函数在物理学中的应用有哪些？"
- **预期系统行为**:
  1. 从问题中识别出核心知识点“指数函数”。
  2. 在 Neo4j 图谱中查询该知识点在物理学中的应用。
  3. 在文档库中检索相关背景信息。
  4. 综合图谱查询结果和文档信息，生成自然语言答案。
  5. 输出推理过程的每一步，以实现可解释性。

### 2.2. 实验结果

调用 `/multi-hop-query` 接口后，系统返回了以下结果：

```json
{
  "final_answer": "指数函数在物理学中的应用包括描述放射性衰变、热传导过程等。",
  "reasoning_path": [
    "步骤 1: 从 RAG 获取到的实体名称为 '指数函数'。",
    "步骤 2: 构造 Cypher 查询在图谱中查找。",
    "   - Cypher 查询: MATCH (math:Math {name: '指数函数'})<-[r:CROSS_DISCIPLINE_LINK]-(other) RETURN math.name AS 数学概念, other.name AS 应用领域, labels(other) AS 学科, r.type AS 应用类型",
    "步骤 3: 从图谱中获取到的结果为 '[{\"数学概念\": \"指数函数\", \"应用领域\": \"物理学\", \"学科\": [\"Physics\"], \"应用类型\": \"描述放射性衰变\"}]'。"
  ]
}
```

### 2.3. 结果分析

1. **答案准确性**: 系统准确识别了知识点及其跨领域应用，生成的答案清晰且具有参考价值。
2. **可解释性**: `reasoning_path` 字段清晰展示了推理过程，验证了系统的透明性。
3. **鲁棒性**: 系统在多数据源协同下表现稳定，未出现明显错误。

## 3. 关键技术点分析

### 3.1. Neo4j 在关系推理中的作用

- **优势**: Neo4j 能高效存储和查询复杂关系。在本项目中，Cypher 查询语言被用来快速获取知识点的跨领域应用。
- **分析**: 通过 `MATCH` 和 `RETURN` 语句，系统能够精准提取“指数函数”在物理学中的应用。

### 3.2. LlamaIndex 的编排能力

- **优势**: LlamaIndex 作为中枢，协调了向量检索和图谱查询。
- **分析**: `rag_query` 和 `kg_query` 函数实现了多跳查询的无缝衔接，显著提升了系统的集成效率。

### 3.3. 向量检索与图谱推理的结合

- **优势**: 向量检索提供了广度，图谱推理提供了深度。
- **分析**: 系统通过结合两种技术，既能回答开放性问题，又能处理结构化查询。

## 4. 总结与展望

本项目成功实现了一个多跳问答系统，结合了知识图谱的深度推理能力和向量检索的广度覆盖能力。实验结果表明，该系统在复杂问题的回答上具有较高的准确性和可解释性。

**未来方向**:
1. **动态图谱更新**: 实现从文档中自动提取知识点和关系，动态更新图谱。
2. **更复杂的推理能力**: 支持多跳、多知识点的复杂推理。
3. **性能优化**: 提升大规模数据下的查询效率。
